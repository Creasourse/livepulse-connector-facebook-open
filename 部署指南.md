# Facebook Ads 连接器部署指南

## 版本信息

- **版本**: v1.8
- **描述**: 同步 Facebook Ads 广告投放数据，支持广告系列、广告组、广告和洞察数据
- **分类**: Marketing

## 环境要求

### 1. 基础环境

- **Java**: JDK 17
- **Maven**: 3.8+
- **PostgreSQL**: 15+
- **Nacos**: 2.5.1+
- **Docker**: 20.10+ (可选)
- **Docker Compose**: 2.0+ (可选)

### 2. 硬件要求

- **CPU**: 2 核心以上
- **内存**: 4GB 以上
- **磁盘**: 20GB 以上

## 部署步骤

### 1. 安装 PostgreSQL 数据库

```bash
# Ubuntu/Debian
sudo apt-get update
sudo apt-get install postgresql-15

# CentOS/RHEL
sudo yum install postgresql15-server
sudo postgresql-setup initdb
sudo systemctl start postgresql
sudo systemctl enable postgresql
```

### 2. 创建数据库和用户

```bash
# 切换到 postgres 用户
sudo -u postgres psql

# 创建数据库
CREATE DATABASE livepulse_facebook_ads;

# 创建用户
CREATE USER facebook_ads_user WITH PASSWORD 'your_password';

# 授权
GRANT ALL PRIVILEGES ON DATABASE livepulse_facebook_ads TO facebook_ads_user;

# 退出
\q
```

### 3. 执行数据库脚本

```bash
# 进入 SQL 脚本目录
cd livepulse-connector-facebook-open/docs/sql

# 执行建表脚本
psql -U facebook_ads_user -d livepulse_facebook_ads -f facebook_ads_schema.sql
```

### 4. 配置 Nacos

#### 4.1 导入配置

在 Nacos 控制台创建以下配置：

**Data ID**: `postgresql-config.yml`
**Group**: `DEFAULT_GROUP`

```yaml
spring:
  datasource:
    driver-class-name: org.postgresql.Driver
    url: jdbc:postgresql://postgresql-host:5432/livepulse_facebook_ads
    username: facebook_ads_user
    password: your_password
    hikari:
      minimum-idle: 5
      maximum-pool-size: 20
      idle-timeout: 300000
      connection-timeout: 30000
      max-lifetime: 1200000

mybatis-plus:
  mapper-locations: classpath*:/mapper/**/*.xml
  type-aliases-package: com.cs.entity
  configuration:
    map-underscore-to-camel-case: true
    cache-enabled: true
    log-impl: org.apache.ibatis.logging.stdout.StdOutImpl
  global-config:
    db-config:
      id-type: auto
      logic-delete-field: deleted
      logic-delete-value: 1
      logic-not-delete-value: 0
```

**Data ID**: `kafka-config.yml`
**Group**: `DEFAULT_GROUP`

```yaml
spring:
  kafka:
    bootstrap-servers: kafka-host:9092
    consumer:
      group-id: facebook-ads-connector-group
      auto-offset-reset: latest
      key-deserializer: org.apache.kafka.common.serialization.StringDeserializer
      value-deserializer: org.apache.kafka.common.serialization.StringDeserializer
    producer:
      key-serializer: org.apache.kafka.common.serialization.StringSerializer
      value-serializer: org.apache.kafka.common.serialization.StringSerializer
```

### 5. 构建项目

```bash
# 进入项目根目录
cd livepluse-connectorx

# 编译打包
mvn clean package -DskipTests

# 查看生成的 JAR 文件
ls -lh livepulse-connector-facebook-open/target/livepulse-connector-facebook-open.jar
```

### 6. 配置应用

创建 `application-prod.yml` 文件：

```yaml
server:
  port: 23010

spring:
  application:
    name: livepulse-connector-facebook-open

# Facebook Ads 定时任务配置
facebook:
  scheduled:
    enabled: true
    campaign-sync:
      cron: "0 0 4 * * ?"  # 每天凌晨4点
    ad-set-sync:
      cron: "0 0 4 * * ?"  # 每天凌晨4点
    ad-sync:
      cron: "0 0 4 * * ?"  # 每天凌晨4点
    insight-sync:
      cron: "0 0 */6 * * ?"  # 每6小时执行一次
```

### 7. 启动应用

#### 方式一：直接启动

```bash
java -jar livepulse-connector-facebook-open/target/livepulse-connector-facebook-open.jar \
  --spring.profiles.active=prod \
  --NACOS_SERVER_ADDR=nacos-host:8848
```

#### 方式二：使用 Docker 启动

```bash
# 构建镜像
cd livepulse-connector-facebook-open
docker build -t livepulse-connector-facebook:1.8 .

# 启动容器
docker-compose up -d

# 查看日志
docker-compose logs -f
```

### 8. 配置 Nginx（可选）

```nginx
upstream facebook-ads-connector {
    server localhost:23010;
}

server {
    listen 80;
    server_name facebook-ads.yourdomain.com;

    location / {
        proxy_pass http://facebook-ads-connector;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;

        # WebSocket 支持
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
    }
}
```

## Facebook Ads API 配置

### 1. 创建 Facebook App

1. 访问 [Facebook Developers](https://developers.facebook.com/)
2. 创建新的应用
3. 添加 Marketing API 产品
4. 配置 OAuth 重定向 URL

### 2. 获取访问令牌

1. 访问 [Graph API Explorer](https://developers.facebook.com/tools/explorer/)
2. 选择你的应用
3. 生成访问令牌（需要 `ads_read` 权限）
4. 选择需要的权限：`ads_read`, `read_insights`

### 3. 配置 Facebook Ads 连接

通过 API 添加 Facebook Ads 连接配置：

```bash
curl -X POST http://localhost:23010/facebook/account \
  -H "Content-Type: application/json" \
  -d '{
    "accountId": "act_123456789",
    "accountName": "My Ad Account",
    "accessToken": "your_access_token_here",
    "appId": "your_app_id",
    "appSecret": "your_app_secret",
    "enabled": true
  }'
```

## 故障排查

### 1. 检查日志

```bash
# Docker 日志
docker-compose logs -f

# 应用日志
tail -f logs/livepulse-connector-facebook-open.log
```

### 2. 常见问题

#### 问题 1：无法连接到 PostgreSQL

检查数据库连接配置：

```bash
psql -U facebook_ads_user -d livepulse_facebook_ads -h postgresql-host
```

#### 问题 2：无法注册到 Nacos

检查 Nacos 地址配置：

```bash
curl http://nacos-host:8848/nacos/v1/ns/instance/list?serviceName=facebook-open-connector-server
```

#### 问题 3：Facebook Ads API 调用失败

检查 API 凭据配置：
- 确认访问令牌有效
- 确认应用有足够的权限
- 确认账户 ID 格式正确

## 数据模型说明

### 核心表结构

1. **facebook_account**: Facebook Ads 账户配置
2. **facebook_campaign**: 广告系列数据
3. **facebook_ad_set**: 广告组数据
4. **facebook_ad**: 广告数据
5. **facebook_ad_insight**: 洞察数据（展示、点击、花费等）
6. **facebook_sync_log**: 同步日志

### 同步频率

- 广告系列/广告组/广告：每天凌晨4点同步最近30天数据
- 洞察数据：每6小时同步最近7天数据

## 安全建议

1. **敏感数据加密**：对访问令牌进行加密存储
2. **访问控制**：配置 Nginx IP 白名单
3. **HTTPS 配置**：生产环境使用 SSL 证书
4. **日志脱敏**：避免在日志中输出敏感信息
5. **令牌轮换**：定期更新访问令牌
